### 🚀 About Me

I'm a Computer Science student at **UET Lahore (2024–2028)**, building toward a career as an **Agentic AI Developer / Software Engineer** — including remote roles. I like working on systems that combine solid software engineering fundamentals with practical AI integration: full-stack apps, automation, and tools that actually reason about the task in front of them, not just respond to it.
